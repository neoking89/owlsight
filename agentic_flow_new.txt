┌────────────────────▼──────────────────────────────────┐
│ When an error occurs in any agent:                    │
│ 1. The error and current context are captured         │
│ 2. Flow returns to RouterPlanningAgent                │
│ 3. RouterPlanningAgent creates a new plan based on    │
│    error information                                  │
│ 4. Context is fully refreshed with the new plan       │
│ 5. Execution continues with the new plan              │
